For Project 2.5, our team focused on extending BestLLM beyond the requirements of Project 2.4 by implementing meaningful new functionality and enhancing the user experience through additional quality-of-life features. The following improvements were successfully designed, implemented, tested, and integrated into the final build.

✅ Implemented Features
🔖 1. Per-User Bookmarking for Posts & Prompts

Posts and prompts now include a bookmark button

Bookmark icon outlines fill when saved and return to outline when removed

A dedicated Bookmarks Page displays all saved content, newest first

Users may filter Posts Only / Prompts Only / Both

Bookmarks persist per-account across sessions

📝 2. Per-User Drafts for Posts & Prompts

"Save Draft" button added to both post and prompt creation screens

Drafts stored per user and persist between sessions

Dedicated Drafts Page to view, resume, or delete saved drafts

Most recent drafts appear first

Users can reopen any draft and continue writing seamlessly

🕓 3. Usable Version History for Posts & Prompts

Each save/edit generates a new version snapshot

"View Version History" button available on user-owned posts/prompts

All revisions displayed chronologically with timestamp indicators

Users can preview past versions and restore them when needed

🕶 4. Anonymous Posting Support

Users can toggle Anonymous Mode when creating or editing posts/prompts

Anonymous content displays "Anonymous" instead of author’s username

Anonymous property persists across drafts and version history restore

Users may switch between public and anonymous after posting

🎨 5. UI Layout, Spacing, and Theming Cleanup

Visual alignment and spacing standardized across the app

Category separation and navigation clarity improved

Consistent card shapes, font sizing, and padding

Better readability and modernized visual hierarchy

All feature pages now match the updated unified design language

📜 6. Activity Log Enhancements

Activity screen now lists posts, prompts, and comments created by the user

Items are displayed in reverse-chronological order

Comments now indicate which post/prompt they belong to

Activity list scroll is smooth and responsive

All log data pulls dynamically and reflects real user history
